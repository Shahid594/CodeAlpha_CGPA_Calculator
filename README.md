# CodeAlpha CGPA Calculator 🎓

A simple and efficient C++ program to calculate the Grade Point Average (GPA) and Cumulative Grade Point Average (CGPA) for students. This project was developed as part of the **CodeAlpha C++ Programming Internship**.

## 🚀 Features
*   **Dynamic Input:** Allows users to input the number of courses dynamically.
*   **Accurate Calculation:** Computes total credits and total grade points using standard academic formulas.
*   **Detailed Output:** Displays individual course grades along with the final overall CGPA.

## 🛠️ Technologies Used
*   Language: **C++**
*   Concepts: Vectors, Loops, I/O Formatting (`<iomanip>`)

## 💻 How to Run
1. Clone this repository to your local machine.
2. Compile the code using a C++ compiler (e.g., GCC):
   `g++ cgpa_calculator.cpp -o cgpa_calculator`
3. Run the executable:
   `./cgpa_calculator` (Linux/Mac) or `cgpa_calculator.exe` (Windows)
